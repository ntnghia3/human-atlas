## Optional licensed-local workflow and reproducibility

1. Future operator supplies authorized files under `.local/terminology-source-cache/m04b2f/`, already covered by the repository's cache ignore rule. Credentials live outside artifacts and command logs. Exported public files never contain absolute local paths or account identifiers.
2. A local manifest pins UMLS, each integrated source version, RF2 edition/module/effective time, FMA release and file digests. A documented source adapter resolves identifier fields and active status without relying on label matching.
3. Compute and retain all CUI joins and structural evidence locally. Write pair decisions into the local profile only. Human ontology reviewers may create exact pair assertions; restricted provenance remains attached even if the review text is original.
4. Use a separate public export allowlist. Each artifact has `useDecision`, `exportDecision`, scope, evidence URL/document locator, responsible rights decision, date, conditions and expiry/recheck trigger. Any transitive dependency with unknown/denied export permission blocks public export. Mixed-license files are split or withheld, not relabelled.
5. Public CI uses only already-cleared inputs, policy and synthetic tests. No network credentials, UMLS subscription or RF2 download is needed. A locally available restricted source must not silently improve the public profile's result.
6. Report public and licensed-local coverage separately. Public reproducibility means the same cleared public inputs yield the same public result. It does not claim that an unlicensed user can reproduce restricted-data outcomes. Authorized users can reproduce local results by acquiring matching releases themselves; retired/unavailable releases are an explicit reproducibility limitation.

If clearance cannot be established, continue public design/testing with an empty bridge registry and emit review-only outcomes. There is no need to block the entire milestone or invent an equivalence fallback. Any future need to publish restricted derivatives is a separate rights decision; no such publication is authorized or attempted by this plan.

## Acquisition order and exit criteria

Acquire metadata and licenses first; then the exact MOH-associated SNOMED edition/history and FMA export; then any usable curated direct bridge; then RF2 SEP/laterality facts; finally optional UMLS and BioPortal discovery. Do not start by downloading the whole Metathesaurus into the public repository.

Admission requires a machine-readable record of artifact identity, version, hash, publisher, actual relation semantics, local-use right, export right, and dependency closure. Missing direct-map evidence means the trusted registry remains empty. Missing source edition means IDENTITY_REVIEW until an explicit reviewed version interpretation is available. No classifier stage may weaken either boundary to reach a coverage target.
